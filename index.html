Yeongsangman — a personal video studio tool

영상맨은 운영자 한 사람이 자기 컴퓨터에서 돌리는 영상 제작 도구입니다. 운영자가 만든 짧은 영상(유튜브 쇼츠)을 운영자 본인의 유튜브 채널에 올리고, 정해 둔 시각에 공개되도록 예약합니다.

Yeongsangman is a desktop tool that one operator runs on their own computer. It uploads short videos the operator made to the operator's own YouTube channel and schedules them to go public at set times.

  • Google 계정으로 연결해 운영자 본인의 유튜브 채널에만 영상을 올립니다.
  • 다른 사람의 계정이나 데이터에는 접근하지 않습니다.
  • 연결 정보는 운영자 컴퓨터에만 암호화해 저장합니다.
