영상맨 개인정보처리방침

시행일: 2026년 11월 26일

1. 이 앱이 하는 일

영상맨은 운영자 한 사람이 자기 컴퓨터에서 실행하는 영상 제작 도구입니다. 운영자가 만든 영상을 운영자 본인의 유튜브 채널에 올리고 공개 시각을 예약합니다.

2. Google에서 받는 정보와 쓰는 곳

운영자가 Google 계정으로 연결하면, 영상맨은 YouTube Data API를 통해 다음만 사용합니다.

  • 채널 기본 정보(채널 이름과 ID): 어느 채널이 연결됐는지 화면에 보여 주는 데만 씁니다.
  • 영상 업로드: 운영자가 승인한 영상과 제목·설명·태그를 운영자의 채널에 올리고 공개 예약을 겁니다.
  • 자막 업로드: 운영자가 켠 경우 영상의 자막 파일을 올립니다.

그 밖의 개인정보(연락처, 이메일 내용, 시청 기록 등)는 요청하거나 읽지 않습니다.

3. 저장과 공유

  • Google 연결 정보(접근 토큰)는 운영자 컴퓨터에만 암호화해 저장하며, 다른 서버로 보내지 않습니다.
  • Google에서 받은 정보를 판매하거나 제3자에게 넘기지 않으며, 광고나 분석에 쓰지 않습니다.
  • 영상맨은 Google API 서비스 사용자 데이터 정책(제한적 사용 요구사항 포함)을 따릅니다.

4. 연결 끊기와 삭제

운영자는 언제든 앱의 계정 화면에서 연결을 지우거나, Google 계정 권한 페이지에서 영상맨의 접근을 취소할 수 있습니다. 연결을 지우면 저장된 토큰도 지워집니다.

5. 문의

이 방침에 대한 문의는 OAuth 동의 화면에 표시된 개발자 연락처로 보내 주세요.

Yeongsangman Privacy Policy

Effective: November 26, 2026

What the app does. Yeongsangman is a desktop tool that one operator runs on their own computer. It uploads videos the operator made to the operator's own YouTube channel and schedules when they go public.

Google data used. Through the YouTube Data API the app uses only: the channel's basic info (name and ID), to show which channel is connected; video upload, to upload approved videos with their title, description and tags and set a publish time; and caption upload, when the operator turns it on. It does not request or read any other personal data.

Storage and sharing. OAuth tokens are stored encrypted only on the operator's computer and are never sent to other servers. Data received from Google is not sold, shared with third parties, or used for advertising or analytics. Yeongsangman's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access. The operator can remove the connection in the app at any time, or revoke access at Google Account permissions. Removing the connection deletes the stored tokens.

Contact. Use the developer contact shown on the OAuth consent screen.
